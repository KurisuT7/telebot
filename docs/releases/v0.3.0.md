# telebot v0.3.0

## 简体中文

此版本增加 telebot 自己的 Telegram 首次授权流程，并明确支持 Gemini Interactions、OpenAI
Chat Completions 和 OpenAI Responses 三种 API 格式。

### 安装

下载 x86_64 或 aarch64 Linux 安装包并使用 SHA256SUMS 校验。解压后运行
sudo ./install.sh --prepare，填写 /etc/telebot/config.toml 和
/etc/telebot/telebot.env，再运行 sudo ./install.sh。

安装器会交互式授权 Telegram 账号、安装 systemd 服务、启动 telebot 并检查状态。配置、
Telegram Session、SQLite 数据和语录存档都保存在 release 目录外。

### 更新

解压新安装包并运行 sudo ./install.sh。部署会在 /opt/telebot/releases 下创建带版本号的
目录，原子切换当前版本，并保留旧版本供回滚。

### 可选语录渲染

示例配置默认关闭语录渲染，因此核心安装不需要 Docker。启用 .q 时，把 quote.enabled 设为
true，再运行 sudo ./install.sh --with-quote。这条可选路径需要 Docker、Docker Compose、Git
和 curl。

### 当前限制

- 安装包面向带 systemd 且 glibc 不低于 2.35 的 64 位 Linux，支持 x86_64 和 ARM64。
- Telegram 授权需要已有账号、手机验证码和可选的 2FA 密码；不支持扫码登录或注册账号。
- OpenAI Chat Completions 没有统一的原生联网搜索协议。

## English

This release adds a native first-run Telegram authorization flow and explicit support for Gemini
Interactions, OpenAI Chat Completions, and OpenAI Responses API formats.

## Install

Download the archive for x86_64 or aarch64 Linux and verify it with SHA256SUMS. Extract it,
run sudo ./install.sh --prepare, fill /etc/telebot/config.toml and
/etc/telebot/telebot.env, then run sudo ./install.sh.

The installer authorizes the Telegram account interactively, installs the systemd service, starts
telebot, and checks its status. Existing configuration, Telegram authorization, SQLite data, and
quote archives are kept outside the release directory.

## Upgrade

Extract the new archive and run sudo ./install.sh. The deployment creates a versioned directory
under /opt/telebot/releases, switches the current symlink atomically, and retains the previous
release for rollback.

## Optional quote rendering

The example configuration leaves quote rendering disabled, so the core installation does not
require Docker. To enable .q, set quote.enabled = true and run
sudo ./install.sh --with-quote; this optional path requires Docker, Docker Compose, Git, and curl.

## Known limitations

- Release packages target 64-bit Linux with systemd and glibc 2.35 or newer on x86_64 or ARM64.
- Telegram authorization requires an existing account, phone login code, and 2FA password when
  enabled; QR login and account registration are not supported.
- OpenAI Chat Completions has no standard native web-search protocol.
